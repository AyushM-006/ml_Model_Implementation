# Retail Sales Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on predicting retail sales using Machine Learning techniques. The goal is to analyze retail sales data, identify patterns that influence sales performance, and build predictive models that can assist businesses in making data-driven decisions.

Three machine learning algorithms were implemented and compared:

- K-Nearest Neighbors (KNN)
- Logistic Regression
- Decision Tree

The project includes data preprocessing, exploratory data analysis (EDA), model training, evaluation, and performance comparison.

---

## 🎯 Objectives

- Analyze retail sales data to identify trends and patterns.
- Build predictive models using different machine learning algorithms.
- Compare model performance using standard evaluation metrics.
- Generate actionable insights for retail business decision-making.

## 🤖 Machine Learning Models

### 1. K-Nearest Neighbors (KNN)

KNN is a non-parametric algorithm that classifies data points based on the majority class among its nearest neighbors.

**Advantages:**
- Simple to implement
- Effective for smaller datasets
- Captures local patterns

---

### 2. Logistic Regression

Logistic Regression predicts categorical outcomes using probability estimation.

**Advantages:**
- Easy to interpret
- Fast training time
- Strong baseline model

---

### 3. Decision Tree

Decision Trees create a tree-like structure to make predictions based on feature splits.

**Advantages:**
- Easy to understand and visualize
- Handles non-linear relationships
- Requires minimal data preparation

---

## 📈 Model Evaluation

The models were evaluated using:

- Accuracy Score
- Confusion Matrix

The performance of all three algorithms was compared to determine the most effective model for retail sales prediction.
